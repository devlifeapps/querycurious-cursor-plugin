# QueryCurious Lifeapps

Consulta o BI da sua empresa no Cursor. O login é o SSO Lifeapps. Cada pessoa vê somente os dados da empresa vinculada ao usuário.

O servidor é `https://query-curious.lifeappsecommerce.com.br/mcp`. O client OAuth `cursor-querycurious-mcp` já está neste plugin. Não há segredo e não há token para colar.

## O que o agente pode fazer

- Listar os conjuntos de dados disponíveis.
- Descrever os campos de cada conjunto.
- Filtrar, ordenar e agregar vendas, pedidos, clientes, produtos e lojas.
- Trazer uma amostra antes de montar uma consulta maior.

A leitura é somente consulta. O plugin não grava no data warehouse.
